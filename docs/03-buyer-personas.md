# 3. Buyer Personas

Three personas based on the audience profile. Every post in the calendar is written for at least one of them.

## Persona 1 - Rahul Varma, 20: 'The Stuck Student'

*"I've watched hundreds of hours of tutorials but I still can't build anything on my own."*

| Attribute | Details |
|---|---|
| Background | 2nd-year B.Tech CSE at a Tier-2 college in Warangal; lives in a hostel; middle-income family |
| Goals | Land an internship by 3rd year; build a GitHub portfolio; feel job-ready |
| Pain points | Tutorial hell; no one reviews his code; confused between web dev, DSA and AI |
| Motivations | Peer success on LinkedIn; fear of being left behind at placements |
| Objections | Price; 'free content exists'; doubts he can keep up |
| Where he spends time | Instagram Reels (2-3 hrs/day), YouTube tutorials, college WhatsApp groups |
| Content that works | Relatable reels, roadmaps, project ideas, challenges, live doubt sessions |
| Key message | Stop watching, start building - ship 5 real projects with a mentor who checks your code. |
| Funnel path | Reel -> roadmap PDF -> #BuildIn30 -> free workshop -> EMI enrolment |

## Persona 2 - Priya Reddy, 24: 'The Career Switcher'

*"I want to move into AI, but I can't quit my job to study."*

| Attribute | Details |
|---|---|
| Background | Software engineer at an IT-services company in Hyderabad, 1.5 years' experience |
| Goals | Switch to an AI/data role at a product company within a year |
| Pain points | Limited time (weekends only); unsure which certifications matter; maintenance work |
| Motivations | Better pay, interesting work, career growth |
| Objections | Time commitment; mentor credibility; course completion |
| Where she spends time | LinkedIn (weekday mornings), YouTube long-form, tech newsletters |
| Content that works | Switch plans, explainers (RAG, LLMs), learner stories, newsletters, LinkedIn Events |
| Key message | Switch to AI in 16 weekends - live mentors, real projects, built around your job. |
| Funnel path | LinkedIn post -> newsletter -> workshop event -> counselling call -> weekend cohort |

## Persona 3 - Srinivas Rao, 48: 'The Careful Parent'

*"I'll pay if I know it really helps my son get a job."*

| Attribute | Details |
|---|---|
| Background | Government employee in Vijayawada; son in final-year B.Tech |
| Goals | A stable job for his son; value for money |
| Pain points | Many institutes, misleading ads, no way to judge quality |
| Motivations | His child's future and security |
| Objections | Fear of scams; lump-sum fees; online vs offline doubts |
| Where he spends time | WhatsApp, Facebook, Telugu YouTube channels |
| Content that works | Transparent fee breakdowns, real student stories, Telugu explainers, counsellor calls |
| Key message | Transparent fees, honest outcomes, EMI from Rs 999/month - talk to a counsellor in Telugu. |
| Funnel path | WhatsApp forward / Facebook post -> Telugu YouTube video -> counselling call -> enrolment |
