| Stage | KPI | How it's calculated | 30-day target | Tracked in |
|---|---|---|---|---|
| Awareness | Reach | Unique accounts that saw content | 2,00,000 | IG Insights, LinkedIn Analytics, YT Studio |
| Awareness | Impressions | Total times content was shown | 6,00,000 | Platform analytics |
| Awareness | Video views (Reels/Shorts) | Plays of 3 seconds or more | 1,50,000 | IG Insights, YT Studio |
| Awareness | Net new followers | End followers - start followers | IG +3,800; LI +1,700; YT +1,200 | Platform analytics |
| Engagement | Engagement rate (by reach) | (Likes + comments + shares + saves) / reach x 100 | IG >= 5%; LI >= 3% | Google Sheets dashboard |
| Engagement | Saves + shares per carousel | Average per post | >= 60 | IG Insights |
| Engagement | UGC submissions | Posts using #BuildIn30 | 300 | Hashtag search |

| Traffic | Website sessions from social | Sessions with UTM source = social | 12,000 | Google Analytics 4 |

| Leads | Landing-page conversion rate | Sign-ups / visitors x 100 | >= 12% | GA4 |
| Leads | Cost per lead (CPL) | Ad spend / leads from ads | <= Rs 60 | Ads Manager + sheet |
| Conversion | Paid enrolments | New paying learners | 150 | Payment records |
| Conversion | Lead-to-enrolment rate | Enrolments / leads x 100 | >= 7.5% | Sheet |
| Conversion | Customer acquisition cost (CAC) | Total marketing spend / new paying learners | <= Rs 1,000 | Sheet |
| Conversion | Return on ad spend (ROAS) | Revenue from ads / ad spend | >= 5x | Ads Manager + sheet |
| SEO | Organic sessions | Visits from Google search | +50% by Mar 2027 | GA4, Search Console |
| SEO | Keyword rankings | Position for target keywords | 5 keywords in top 30 in 90 days | Search Console |
| Retention | Email / WhatsApp open rate | Opens / delivered x 100 | Email >= 30% | Email tool |
| Advocacy | Referral enrolments | Enrolments with ambassador code | 20 | Sheet |

## Measurement plan

- **UTM links on every post:** e.g. `?utm_source=instagram&utm_medium=social&utm_campaign=newyearnewskill_dec26&utm_content=d22_reel`.
- **Weekly review (every Monday):** update the KPI Tracker sheet, compare against targets, and note top and bottom 3 posts.
- **Optimise:** after week 2, move ad budget to the platform with the lowest cost per lead; A/B test reel hooks and thumbnails.
- **Final report (31 Dec):** results vs targets, learnings, and plan for January.
